# EEGT is open for inspection

We are publishing a small reproducible experiment on recurring patterns in around-ear EEG: two public CC0 sources, eight selected recordings, 40,500 two-second channel windows and 27 numerical tokenizer configurations.

The result is a useful disagreement. Spectrum and time-frequency models share more structure than either shares with the waveform-shape model, but none of these comparisons establishes a universal vocabulary. Coverage can remain high even when most assignments concentrate in a few codes.

The [research note](experiment-002.md) links the complete numerical results, inputs, controls and limitations. The [v0.2.0 release](https://github.com/h3ro-dev/eegt/releases/tag/v0.2.0) supplies native voltage slices, processed windows, assignments and codebooks. Source code is MIT; the derived numeric data from the two CC0 sources retain CC0 terms and source attribution.

Contributions should begin with a reproducible defect or a numbered protocol proposal. The most useful next comparisons test additional around-ear recordings, acquisition perturbations, a compatible learned codec, or genuinely separate model discovery. The current models are LLM-authored numerical algorithms, and the current recordings are cEEGrid data. Independent pretrained-LLM discovery and physical Neurable transfer have not been demonstrated.
