## Independent validation

- **Snapshot and freeze:** All 74 `input-manifest.json` entries match size and SHA-256 (273,959,625 bytes total). The public [metadata freeze commit `700b2d0`](https://github.com/h3ro-dev/eegt/commit/700b2d0b6fed5753bd6d7ae11e753effb35408c8) contains the exact protocol and source-manifest bytes in this snapshot. It selects 6 source participants × 2 sessions and records 108 reserved files, using the pinned [OpenNeuro EESM23 source commit](https://github.com/OpenNeuroDatasets/ds005178/commit/a57deb78cf1294497db88d73aaed06813850f236). I checked all 12 public git-annex pointers against the frozen byte counts and SHA-256 identities (1,865,998,768 selected source bytes). The source paper identifies EESM23 and its repeated ear recordings ([Mikkelsen et al., 2025](https://www.nature.com/articles/s41597-025-04579-8)). The freeze commit establishes the recorded selection; the snapshot alone cannot prove every prior human or process exposure.
- **Native source and units:** The one included original SET (`sub-001/ses-001`) hashes to its pinned public annex identity. Native MATLAB floats and MNE-decoded values × 10⁶ agree on 764 finite values at five deterministic positions; maximum absolute difference is `4.55e-13 µV`, with identical finite masks. The file has 5 native channels in order `RB, RT, LB, LT, ELE`; only the four BIDS-declared EEG microvolt channels enter analysis. Rate is 250 Hz, reference metadata says average, and ELE is excluded. Re-extracting the first 60 seconds produced 117 feature windows, 69 QC passing, with exactly equal times, masks, and all three feature arrays in the archive. This verifies decoding, not amplifier calibration.
- **Status and exposure:** All 12 candidates are `QUALIFIED`, `EXTRACTED`, `PAIRED`; no failure reason, decoder warning, or native gap appears. Every file exceeds the frozen four-hour minimum. Qualified full-file duration is **86.383621 h**; selected analysis is **48 h**. Twelve archives each contain 28,797 two-second windows at a 0.5-second hop: **345,564 candidates**, **306,392 QC passing**. Missing/nonfinite samples remain in the QC denominator. No gaps were present in this cohort, so the gap-splitting path was exercised by unit tests, not by these 12 files.
- **Per-record and event arithmetic:** From every feature archive, I recomputed the three standardized coordinate medians, two-second pre/post boundary scores, thresholded peaks, scored-center denominators, event rates, and one-to-one F1 match counts. All 12 JSON and SQLite metrics match. There are **47,476 events**, **291,911 eligible scored centers per view** (875,733 across the three views), and **36** within-record view-pair agreement rows. Every event time matches SQLite; maximum score difference is `1.34e-15`. Scored-center minutes are an exposure measure, not 48 wall-clock hours or independent observations.
- **Paired inference:** Independently formed all **36 cross-session distance cells per view** and all **720 permutations per view** (108 cells and 2,160 assignments total). The lower-tail counts are morphology **22/720 = 0.03056**, spectrum **68/720 = 0.09444**, coordination **133/720 = 0.18472**. Three-view Bonferroni values are **0.09167, 0.28333, 0.55417**. Same-person mean distance is lower than off-diagonal mean in all views, but every adjusted p exceeds 0.05. This is a six-person descriptive result under an exchangeable-pairing model; it does not identify a neural cause or population reliability.
- **Expanded index and reporting:** Corpus-v2 retains all **55** old rows (54 qualified, 1 quarantined), adds the **12** new qualified rows, and contains **122** source-file rows (110 + 12) totaling **23,401,180,576** recorded verified bytes. SQLite integrity and foreign-key checks pass. The source-local participant count is **61**, not a global unique-person census. The note and page reproduce all three comparison rows and all 12 per-record rows exactly to their displayed precision; their 86.38/48-hour, 345,564/306,392-window, 66-qualified/309.85-hour figures match the JSON. The heatmap uses separate view scales and the same anonymous row/column ordering as the matrices. The numerical method takes wave arrays, rate, and technical validity; grouping keys enter only after descriptors are fixed. The reused baseline model hash is unchanged; no refit or pretrained inference occurred.
