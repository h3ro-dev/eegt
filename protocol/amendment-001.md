# Prefit implementation clarification: filter padding

2026-09-24, before any tokenizer was fitted. The frozen protocol named a fourth-order per-window forward/backward Butterworth filter but did not specify its padding. A synthetic 10 Hz waveform sampled at 250 and 500 Hz exposed unequal physical padding under SciPy's sample-count default: interior correlation was 0.997119, below the prespecified test requirement of 0.999. Fixed 0.5-second reflected padding gives 0.999950 on the same check. The implementation now uses `padlen=round(0.5 * native_rate)`. The test threshold is unchanged. QC and source selection are unaffected. Prepared derived arrays from the first engineering pass are rebuilt before any fit; that pass had no model results. No input source or protocol JSON is silently replaced.
