## Question, selection and denominator

The descriptive question is how much of **original versus independent-phase** landmark agreement at a 25 ms tolerance can arise when the independent-phase landmark side keeps its local event density, channel, event stratum, coarse timing and event support width, but loses exact within-bin timing. This is a conditional timing null on detected event tables, not a waveform surrogate or a physiological/artifact attribution test. A large raw match and a small raw-minus-null contrast would show tolerance/density saturation for this conditional null. A contrast above it would remain compatible with unmodeled waveform, filter, reference, clock and biological mechanisms.

The source contains 122 selected 30-second blocks from six source-local people with two sessions each, totaling 12 person/session cells. The fixed resource-bounded tranche is **the lowest `array_row` for each `(source_subject, session)`** in the accepted `native-selected-curator.json`: rows `0, 11, 23, 35, 47, 48, 59, 71, 81, 92, 104, 112` in ascending row order. It contains 12/122 selected blocks (9.84%), one block per person/session, six people and two sessions per person. The other 110 blocks are explicitly `NOT_RUN` for this tranche. Selection uses frozen provenance only, never event counts or match outcomes. There is no substitution for a failed first block. One window per session is too thin for a reliability or population claim.

The primary descriptive contrast is computed within each block: `raw_pooled_F1_25ms - median(99 matched-null pooled_F1_25ms)`. The same calculation at 10 and 50 ms is sensitivity only. Pool matched and eligible accepted event counts over four native channels × four accepted strata before calculating F1; do not average stratum F1s or count guarded duration sixteen times. Keep block results with person and session keys. For six person-level descriptions, average the two session-specific block contrasts within person, then take an equal-person mean only when both sessions completed. Blocks and draws are not independent people. No empirical p value, sign-flip test, correction family, confidence interval for people, or selection of a favored person/stratum is proposed here. Report the raw original-versus-phase F1 beside the null distribution and the exploratory excess; do not overwrite the published raw ~0.835 pooled result, whose published denominator is broader than this 12-block tranche.

## Conditional timing null

For each `array_row`, native channel and accepted event stratum, hold the original-side events fixed. On the independent-phase side, first retain only events whose **complete expanded support** lies in the same accepted common guarded interval. With that unchanged eligible count, draw 99 independent timing controls. `timing_matched_control` places each phase event's center uniformly in its feasible part of the same **1.0-second bin anchored to the left endpoint of its common guarded interval**. Its support width and exact signature, guarded interval, within-bin count and stratum count remain fixed. Seeds are `4201200 + array_row*1000000 + channel*100000 + stratum_index*10000 + draw`, with stratum indices 0–3 in accepted `MATCH_STRATA` order and draws 0–98. The same draw is matched at 10, 25 and 50 ms. The RNG is NumPy `default_rng`; pin its runtime version before execution.

The null preserves local density only at the fixed bin width. It does not preserve fine spacing, refractory constraints, exact morphology, a realizable waveform, or cross-channel event synchrony. It cannot turn a synthetic/detected event association into a neural interpretation. Record all 99 null F1 values and the fixed 5th, 50th and 95th sorted observations as descriptive spread, with `raw - median` explicitly labeled exploratory. No draw is dropped or replaced after seeing a result. Empty/empty event strata have null F1 and still contribute zero counts to a pooled F1; if the whole block has no eligible events, the pooled F1 and excess are `NOT_ESTIMABLE`. The runtime identity is pinned to Python 3.12.12, NumPy 2.5.3 and SciPy 1.18.1 in `PROTOCOL.json`; the runner rejects a mismatch and records the observed versions in each stage receipt.
